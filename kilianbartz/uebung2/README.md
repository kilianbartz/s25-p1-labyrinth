Dieses Verzeichnis enthält mein Godot Projekt zum zweiten Übungsblatt Spieleprogrammierung im Sommersemester 2025.

Enthalten:

- Ordner addons: enthält terrain3D Abhängigkeit
- Ordner animations: enthält einige Animation Libraries
- Ordner audio: enthält Umgebungsgeräusche
- Ordner demo: enthält die Hauptszene `demo.tscn`, welcher auf der Terrain3D Demo basiert
- Ordner materials
- Ordner NPC: enthält alle Assets für den NPC
- Ordner Player: enthält Assets für den Spieler
- Ordner scene: enthält Modelle, aus der die Szene aufgebaut ist
- credits.md: Enthält die Quellen aller externer Ressourcen
- llmcon.gd: Skript zur Kommunikation mit dem LLM Provider
- ollamacon.gd: Skript zur Kommunikation mit lokalem Ollama Server
- ttscon.gd: Skript zur Kommunikation mit dem TTS Server
- ui.gd: Skript für das User Interface
- Ordner tts: Simple API für einen Piper TTS Server, siehe dortige README.md
- **bericht.pdf**
